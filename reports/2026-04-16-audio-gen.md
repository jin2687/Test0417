## 新規モデル

### Mistral Voxtral TTS

- **組織**: Mistral AI
- **公開日**: 2026-03-26
- **ライセンス**: オープンウェイト ✅ 商用可(Apache 2.0 表記、要確認)
- **サイズ**: 4B / 必要VRAM: 8GB 推奨
- **できること**:
  - リアルタイム音声合成(9言語: 英仏独西蘭葡伊ヒンディー・アラビア)
  - 数秒の入力からのボイスアダプテーション
  - 20 プリセット + カスタムボイス
  - エッジデバイス推論可
- **ベンチマーク/比較**: ElevenLabs 相当の音質を低コストで実現と公式主張
- **動かし方**: HF Inference / ローカルデプロイ
- **リンク**: [Dataconomy](https://dataconomy.com/2026/03/30/mistral-unveils-open-source-tts-model-for-voice-agents/) / [TechCrunch](https://techcrunch.com/2026/03/26/mistral-releases-a-new-open-source-model-for-speech-generation/)
- **注目度**: 🔥
- **ステータス**: 🆕 新規

## 更新モデル

### Suno v5.5

- **組織**: Suno Inc.
- **公開日**: 2026-03-26
- **ライセンス**: [API-only] ⚠️ 商用利用は契約による
- **できること**:
  - 歌唱ボイスのカスタマイズ(最多要望機能)
  - 長尺曲生成(従来より尺拡張)
  - より表現力豊かな音声合成
  - カスタムモデル学習
- **ベンチマーク/比較**: 公式発表で「最も表現力豊かなモデル」
- **動かし方**: API (Pro / Premier プラン)
- **リンク**: [公式ブログ](https://suno.com/blog/v5-5)
- **注目度**: 🔥
- **ステータス**: 🔄 更新

### Stable Audio 2.5

- **組織**: Stability AI
- **公開日**: 2026年初 / 4月に本格展開
- **ライセンス**: API + 部分的なオープンモデル ✅ 商用可(条件付き)
- **できること**:
  - 3分間楽曲を H100 で約2秒で生成
  - オーディオインペインティング(既存音声の続き生成)
  - エンタープライズ Brand Studio 向け
- **ベンチマーク/比較**: 従来 50 ステップ → 8 ステップに短縮(公式発表)
- **動かし方**: API / Brand Studio
- **リンク**: [公式](https://stability.ai/stable-audio)
- **注目度**: 🔥
- **ステータス**: 🔄 更新
