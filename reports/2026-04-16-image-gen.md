## 継続注目モデル

### FLUX.2 [klein]

- **組織**: Black Forest Labs
- **公開日**: 2026-01-15
- **ライセンス**: 4B版 Apache 2.0 ✅ 商用可 / 9B版 FLUX Non-Commercial License ⚠️ 非商用
- **サイズ**: 4B / 9B / 必要VRAM: 13GB 〜
- **できること**:
  - Text-to-Image 生成(1秒未満のレイテンシ)
  - 同一アーキテクチャでの画像編集(生成・編集統合)
  - マルチリファレンス生成
- **ベンチマーク/比較**: 32B FLUX.2 Dev と同等品質を高速化(公式発表)
- **動かし方**: ローカル / ComfyUI
- **リンク**: [公式ブログ](https://bfl.ai/blog/flux2-klein-towards-interactive-visual-intelligence) / [HF 4B](https://huggingface.co/black-forest-labs/FLUX.2-klein-4B) / [HF 9B](https://huggingface.co/black-forest-labs/FLUX.2-klein-9B) / [GitHub](https://github.com/black-forest-labs/flux2)
- **注目度**: 🔥
- **ステータス**: 🔄 継続注目

### Qwen-Image-2.0

- **組織**: Alibaba
- **公開日**: 2026-02-10
- **ライセンス**: Qwen License ✅ 商用可
- **サイズ**: 7B / 必要VRAM: 24GB 目安
- **できること**:
  - 高精度テキストレンダリング(日中英を含む長文プロンプト)
  - 生成・編集の統合モデル
  - ネイティブ 2K 解像度
- **ベンチマーク/比較**: AI Arena の Text-to-Image / 画像編集部門で #1(公式発表)
- **動かし方**: ローカル / HF Inference
- **リンク**: [公式ブログ](https://qwenimages.com/blog/qwen-image-2-release) / [HF](https://huggingface.co/Qwen/Qwen-Image) / [GitHub](https://github.com/QwenLM/Qwen-Image)
- **注目度**: 🔥
- **ステータス**: 🔄 継続注目

### LongCat-Image-Edit-Turbo

- **組織**: Meituan
- **公開日**: 2026-02-03
- **ライセンス**: Apache 2.0 ✅ 商用可
- **サイズ**: 6B / 必要VRAM: 8GB 目安
- **できること**:
  - 多言語テキストレンダリング(日本語・中国語)
  - インペイント・スタイル転送
  - 元モデル比 10倍高速化(蒸留版)
- **ベンチマーク/比較**: T2I-CoreBench オープンソース部門 #2(FLUX.2 Dev 32B に次ぐ)
- **動かし方**: ローカル / ComfyUI
- **リンク**: [HF](https://huggingface.co/meituan-longcat/LongCat-Image) / [GitHub](https://github.com/meituan-longcat/LongCat-Image) / [arXiv](https://arxiv.org/abs/2512.07584)
- **注目度**: ⭐
- **ステータス**: 🔄 継続注目

### HunyuanImage-3.0-Instruct

- **組織**: Tencent
- **公開日**: 2026-01-26 (Instruct 版)
- **ライセンス**: Tencent OpenSource Agreement ✅ 商用可
- **サイズ**: 80B MoE(64エキスパート)/ 必要VRAM: 90GB(FP8 量子化で 54GB)
- **できること**:
  - テキスト・画像トークン統一処理
  - Image-to-Image 編集(Instruct 版の特徴)
  - 推論型プロンプト強化
- **ベンチマーク/比較**: 従来 DiT パイプラインより推論効率向上(公式発表)
- **動かし方**: ローカル(大規模GPU)/ vLLM 加速対応
- **リンク**: [HF](https://huggingface.co/tencent/HunyuanImage-3.0-Instruct) / [GitHub](https://github.com/Tencent-Hunyuan/HunyuanImage-3.0) / [arXiv](https://arxiv.org/abs/2509.23951)
- **注目度**: ⭐
- **ステータス**: 🔄 継続注目
